# ControleBiblioteca

**Bibliotecaria:** Eloah Saito

 # Descricao
 Sistema para controle e gestao de acervo de livros e emprestimos bibliotecarios.

## Objetivo
Facilitar a organizacao do acervo e automstizar o controle de emprestimos de livros.

## Publico-alvo
Bibliotecarios, alunos e professores.

## Principais funcionalidades
 Cadastro e pesquisa de livros
Registro e renovacao de emprestimos
Controle de devolucoes e leitores
